# Product page header

`product-page-header-1.0.4.png` is the separate wide promotional banner for Retro LUMIX Sync, designed for the App Store product page header.

- Canvas: 3840 × 1646 pixels, RGB PNG, no alpha.
- Created with the built-in image-generation tool using the exact prompt in `banner-prompt.txt`.
- The generated 1915 × 821 image was mechanically resized with macOS `sips` to Apple's required header dimensions. No content edits were applied.
- Original artwork contains no manufacturer logos, Apple devices, UI, or text. The camera, travel photographs, and location motif represent photo importing and optional geotagging.
- Before publication, inspect the App Store Connect product page preview for device-specific cropping.

Specifications: https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications
